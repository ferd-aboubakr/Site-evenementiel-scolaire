# 🎉 Site Événementiel Scolaire - Journée Portes Ouvertes 2025

Ce projet consiste à concevoir et développer le front-office du site web de la **Journée Portes Ouvertes 2025 du Lycée Excellence**.

🎯 Objectif : offrir une expérience utilisateur moderne, accessible et interactive pour informer les visiteurs sur l’événement.

---

## 🚀 Aperçu

Le site permet aux utilisateurs de :
- Consulter le programme de la journée
- Découvrir les activités proposées
- S’inscrire à l’événement
- Contacter l’établissement

Le projet met l’accent sur :
- l’expérience utilisateur (UX)
- le design moderne (UI)
- la responsivité
- l’accessibilité (WCAG)
